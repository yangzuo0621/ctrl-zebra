## 2. 宿主环境与无障碍基线结果

- **窄侧栏自适应 (约 300px 宽度)**：目前在 300px 窄宽度下，多按钮行（如 `Saved Sessions` 控件组与 Composer 操作组）会出现挤压折行，需要重构 Shell 与弹性布局（映射至 T1103）。
- **四类 VS Code 主题适配 (Dark+, Light+, High Contrast, High Contrast Light)**：当前使用了基础的 `--vscode-*` 变量，但在高对比度（High Contrast）下，焦点轮廓（Focus Ring）与边框分界线不清晰（映射至 T1102）。
- **200% VS Code 缩放**：滚动条与 Composer 输入框在 200% 缩放下会出现重叠现象，需统一组件内部与外边距 Token（映射至 T1102, T1105）。
- **纯键盘与 Screen Reader**：控件全流程可到达，但部分 Button 缺乏显示的 `aria-label`；流式更新时缺少针对 `aria-live` 的分级通知（映射至 T1108）。

## 3. 问题清单与后续任务映射

1. **ISSUE-UX-01 (严重度: 高)**: 历史会话与 Checkpoint 面板常驻在主界面顶部，严重干扰聊天与 Composer 的核心视觉焦点。 -> **映射至 T1103 (重构 Webview 信息架构)**
2. **ISSUE-UX-02 (严重度: 高)**: 首次打开未区分 Ready / 未配置 Provider 状态，无引导与示例任务。 -> **映射至 T1104 (完善首次使用和配置引导)**
3. **ISSUE-UX-03 (严重度: 中)**: 文本与代码渲染缺乏 Markdown 支持与一键复制；用户离开底部后强制滚动体验差。 -> **映射至 T1105 (改善对话阅读与 Composer)**
4. **ISSUE-UX-04 (严重度: 中)**: Tool 执行与审批卡片层级平铺，未按“摘要 → 影响范围 → 详细参数”渐进披露。 -> **映射至 T1106 (简化 Tool 与审批反馈)**
5. **ISSUE-UX-05 (严重度: 中)**: 会话以纯时间戳呈现，缺少主题摘要与更加易用的侧滑抽屉。 -> **映射至 T1107 (改善会话、Checkpoint 与恢复体验)**
6. **ISSUE-UX-06 (严重度: 低)**: 全局设计 Token 与语义色彩未统一规范。 -> **映射至 T1102 (建立视觉 Token 和基础组件)**
