# 阶段 22：Preview 与 GA 工程就绪

## 1. 阶段目标

补齐外部协作、依赖维护、数据升级、成本控制、脱敏诊断、性能预算和可重复发布所需的工程能力，
使 Preview 反馈能够被安全处理，并为后续 GA 决策提供证据。

本阶段不自动发布任何版本。实际 Marketplace 发布、凭据配置、版本提升、提交、推送和 Release
仍需要用户对精确操作的明确授权。

## 2. 前置条件与范围

- 阶段 15–21 已完成。
- T1502–T1503 已建立覆盖率和跨平台基础，本阶段不重复创建第二套门禁。
- 所有诊断、发布产物、fixture 和日志继续排除 Secret、工作区正文、完整对话和可重放授权。
- 涉及 GitHub Actions、Dependabot、VSCE 或 Marketplace 的任务开始前必须通过 Context7 核对当前
  官方文档，并固定 Action 与工具版本。

本阶段不包含遥测后端、自动错误上传、云账户、自动合并依赖 PR、自动生成发布说明、自动提升版本、
自动发布或 GA 日期承诺。

## 3. 任务

### T2201：补齐仓库治理与协作文档

增加与现有权威规则一致的 `CHANGELOG.md`、`CONTRIBUTING.md`、`SECURITY.md`、Issue/PR 模板和
必要的所有权说明；不得复制或冲突于 `AGENTS.md`、`docs/security.md` 和 release checklist 的事实。
测试链接、模板字段、秘密报告路径和文档一致性。

### T2202：建立受控依赖更新策略

配置 Dependabot 或等价的受审查更新机制，覆盖 pnpm 与 GitHub Actions；保持锁文件、固定 SHA、
更新频率、分组和并发上限；不自动合并。测试配置语法、目录、生态、目标分支和 Action 固定规则。

### T2203：实现会话格式迁移或旧格式只读降级

先根据真实格式差异选择非原地迁移或旧版本只读打开；保留源数据；新会话只有完整提交后可见；
迁移失败不破坏源会话；未知未来格式拒绝猜测。测试每个受支持旧 fixture、重复迁移、磁盘/写入失败、
损坏源、取消、回滚、只读提示和版本目录边界。

### T2204：实现单次 Run Token 与成本护栏

基于阶段 15 的估算和实际 Usage 定义用户可配置的 Run 上限、预警和强制停止；不得宣称估算金额
等于 Provider 账单；超限是独立、可恢复、无迟到副作用的终态。测试估算/实际边界、Tool 循环、
无 Usage Provider、取消优先、配置无效和恢复展示。

### T2205：实现用户主动的脱敏诊断导出

导出扩展/VS Code/平台版本、Provider 类型、稳定错误类别、MCP 状态和有界运行信息；默认排除密钥、
授权头、端点凭据、命令参数、路径、工作区内容、对话正文和原始第三方错误；导出前显示内容和目标。
测试脱敏、大小上限、损坏状态、取消、写入失败、不同平台和无配置路径。

### T2206：建立可重复的发布流水线与版本一致性门禁

验证版本、CHANGELOG、锁文件、VSIX provenance、分支/标签和 release checklist 一致；构建并保存
可验证产物；生成第三方依赖与许可证清单以及可选的标准 SBOM，审计 VSIX 实际内容与声明依赖；
禁止不兼容许可证、未声明可执行文件和开发缓存进入产物。发布步骤默认关闭或要求受保护环境人工
确认；Secret 仅来自 CI Secret store。测试普通构建、版本错配、缺失说明、许可证/SBOM 差异、
意外文件、错误分支、凭据缺失、重复标签和发布前取消。

### T2207：完成 Marketplace 素材与发布烟雾证据

补齐许可合规的图标、截图、描述、隐私/支持链接和已知限制；在三类 OS 的代表路径验证安装、激活、
Provider 配置、多轮、文件工具、MCP 限制、删除和诊断导出；产物不包含 fixture、缓存或私有状态。

### T2208：建立性能与资源预算基线

在固定 fixture 与可重复环境中测量 Extension 激活、Webview 首次可用、长会话恢复、大型工作区搜索、
MCP 连接/目录加载、稳态与峰值内存、Webview bundle 和 VSIX 大小；先记录真实分布，再为高价值指标
设置有证据的防回退阈值。平台噪声与产品回退必须可区分，阈值调整需要独立证据，不通过减少功能、
跳过安全检查或隐藏慢路径达标。测试基准命令可重复、fixture 有界、输出机器可读、产物不提交且 CI
失败信息可操作。

## 4. 阶段门禁

- 外部贡献、安全报告和变更记录入口完整且不与权威文档冲突。
- 依赖更新始终经过审查，Actions 和发布工具保持固定版本。
- 每个受支持旧格式都有迁移或只读证据，失败不损坏源数据。
- Run 成本护栏可配置、可取消且不把估算伪装成账单。
- 诊断导出默认脱敏、有界、用户预览并主动保存，不引入遥测。
- 发布流水线可重复、可验证，依赖/许可证/SBOM 与 VSIX 内容一致，默认不执行实际发布。
- 激活、首屏、恢复、搜索、MCP、内存和产物大小有可重复基线，高价值指标存在防回退证据。
- 三平台代表烟雾路径有证据。
