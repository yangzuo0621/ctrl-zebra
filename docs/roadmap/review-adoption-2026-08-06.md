# REVIEW-2026-08-06 采纳与处置矩阵

## 1. 文档目的

本文档记录 [2026-08-06 工程评估](../reviews/REVIEW-2026-08-06.md) 中每项问题和建议的正式处置，
避免外部评估在进入路线图时被遗漏或被误当成权威实施规格。

本文档只拥有“评估项如何处置以及为什么”的追踪关系。任务顺序、状态、完成证据和当前执行点仍以
[实施计划索引](../implementation-plan.md) 为准；目标、产物、测试、排除项和阶段门禁仍以对应阶段
规格为准。REVIEW 中的代码草案、工作量和优先级不因在此引用而成为公共契约。

处置值只有以下四类：

- `已规划`：已进入任务台账和阶段规格。
- `部分规划`：可独立、安全实施的部分已进入任务，其余部分有明确前置或决定。
- `候选`：保留在后续能力清单，尚未进入任务台账。
- `不单列`：已有任务完整覆盖，或缺少当前用例而明确不建立独立任务。

## 6. 维护规则

- REVIEW 内容发生变化时不自动改变本矩阵；必须通过路线图变更控制逐项修订。
- 任务完成状态只在实施计划记录，本矩阵不复制状态或 PR 证据。
- `部分规划` 或 `候选` 项只有在前置决定完成并新增阶段规格后才能进入实现。
- 没有 Task 的项目不允许通过相邻任务、维护或“兼容性修复”顺带实施。
